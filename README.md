# 杀戮尖塔 2：Stay Alive 模组更新

适用游戏版本：v0.98.3。模组当前版本：1.1.0。

## 两台电脑如何更新

首次从本仓库下载 `update-mod.ps1` 和 `更新模组.cmd`，放到游戏目录，与 `SlayTheSpire2.exe` 放在一起。

退出游戏，双击“更新模组.cmd”。完成后两台电脑确认版本相同，再启动游戏联机。

脚本仅更新 `mods/StayAlive` 下的 DLL、PCK 和版本记录。更新前备份旧模组，下载后核对 SHA256（检查文件是否完整），失败会恢复旧文件。

账户编号、联机配置、存档、不死开关选择不随更新覆盖。曾使用旧迁移包的电脑仍需先处理重复编号；这个更新器不负责迁移存档。

游戏内右上角按钮或 F8 切换不死。当前开关未做联网同步，联机双方需保持相同状态；尚未完成双机实测。

## 发布新版本

源码位于 `src`。安装 .NET 9 或更新的 SDK 后运行：

```powershell
.\publish-local.ps1 -GameDir 'D:\1\Slay the Spire 2' -Version '1.1.1'
```

脚本编译并生成新版本 PCK、文件哈希和 `update.json`。检查差异后提交推送仓库即可，其他电脑再次运行更新器就会获取新版本。

不要覆盖旧版本目录，也不要更改模组代码却沿用旧版本号。游戏联机按模组名称及版本检查兼容性。

仓库不包含原版游戏、游戏依赖库、账户配置、个人存档或访问密钥。
